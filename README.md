# HTTP Download Speed Benchmark

CLI-приложение на Python для измерения скорости загрузки данных по протоколу HTTP.

Программа выполняет 10 последовательных HTTP GET-запросов к указанному URL, измеряет время полной загрузки каждого ответа и рассчитывает итоговую статистику.

## Требования

- Python 3.10 или выше.
- Доступ к интернету.

Используются только стандартные библиотеки Python. Устанавливать дополнительные зависимости не требуется.

## Запуск

Перейдите в директорию проекта:

```bash
cd project
```

Запустите программу, передав URL файла в качестве аргумента:

```bash
python benchmark.py <URL>
```

### Примеры

Тестирование на файле размером около 50 MB:

```bash
python benchmark.py https://storage.googleapis.com/ml-india-staging/tmp/sample-50mb.jpg
```

Тестирование на файле размером около 10 MB:

```bash
python benchmark.py https://storage.googleapis.com/ml-india-staging/tmp/sample-10mb.png
```

## Как работает программа

1. Принимает URL файла через аргумент командной строки.
2. Выполняет 10 HTTP GET-запросов строго последовательно.
3. Полностью считывает тело каждого HTTP-ответа блоками по 64 KB.
4. Измеряет время выполнения каждого запроса.
5. Отображает прогресс загрузки.
6. Рассчитывает и выводит итоговую статистику.

## Результаты

Для каждого запроса выводятся:

- Время полной загрузки ответа.
- Объём загруженных данных.

В итоговой статистике отображаются:

- **Среднее время** — среднее арифметическое времени всех запросов.
- **Медианное время** — медиана времени всех запросов.
- **Всего скачано** — суммарный объём загруженных данных.
- **Общее время** — сумма времени выполнения всех запросов.
- **Средняя скорость загрузки** — суммарный объём загруженных данных, разделённый на общее время загрузки.

## Единицы измерения

Используются десятичные единицы измерения:

| Показатель | Единица | Значение |
|---|---|---|
| Время | секунда (sec) | 1 секунда |
| Объём данных | MB | 1 MB = 1 000 000 байт |
| Скорость загрузки | Mbps | 1 Mbps = 1 000 000 бит/с |

Средняя скорость загрузки рассчитывается по формуле:

```text
Speed (Mbps) = Total Bytes × 8 / Total Time / 1 000 000
```

Скорость отражает среднюю пропускную способность загрузки за весь тест, а не максимальную скорость интернет-соединения.

## Обработка ошибок

Программа обрабатывает следующие ситуации:

- HTTP-ошибки (например, 404 или 500).
- Ошибки URL и сетевого соединения.
- Тайм-аут подключения или ожидания данных.
- Отсутствие успешно загруженных данных.

При возникновении ошибки программа выводит сообщение и завершается с ненулевым кодом возврата.

## Ограничения

- Выполняется ровно 10 последовательных запросов.
- Каждый запрос должен возвращать конечный HTTP-ответ. Бесконечные потоки данных не поддерживаются.
- Тайм-аут 30 секунд применяется к сетевым операциям, а не ограничивает общую продолжительность загрузки файла.
- Результаты могут зависеть от скорости сети, удалённого сервера и текущей сетевой нагрузки.
